# Reports

Use these folders for reproducible developer handoffs:

- `backend/` — DeepSeek Harness
- `computer/` — Qoder
- `ui/` — OpenCode
- `source-inventory.md` — senior-maintained checkout versions and sparse contents
- `open-mouse-connect-plan.md` — canonical OpenMausBot→Zero capability roadmap, Phase 0 evidence, and gates
- `gap-matrix-2026-10-26.md` — cross-lane status matrix (source / offline / live / blocked / out of scope)

Each report should state: ticket, date/time, exact repo commit, scope, steps/commands, evidence, result, files changed, limitations, and next dependency. Redact all secrets and private computer content. Label documentation-only analysis separately from live verification.
